# C. Maximum Subarray Sum 📊

## 题目大意 🤔
给定一个长度为 `n` 的数组 `a1, a2, ..., an` 和一个正整数 `k`，但数组 `a` 的一部分缺失。你的任务是填充缺失的部分，使得数组的最大子数组和恰好为 `k`，如果没有解，报告无法找到解决方案。

形式上，你将得到一个二进制字符串 `s` 和一个部分填充的数组 `a`，其中：

* 如果你记得 `ai` 的值，那么 `si = 1`，并且给出了 `ai` 的实际值。
* 如果你不记得 `ai` 的值，那么 `si = 0`，并且给出了 `ai = 0`。

所有已记得的值满足 `|ai| ≤ 10^6`。然而，你可以使用最大为 `10^18` 的值来填充那些你不记得的部分。如果解存在，那么也可以证明存在一个满足 `|ai| ≤ 10^18` 的解。

## 题目思路 💡

本题的关键点：要关注`不变量`和`分类讨论`。

`不变量`: 所有`'0'`隔开的数组段中的最大子段和是无法改变的。

`分类讨论`: 

① 某个数组段的最大字段和 > k, 这个时候无论怎么操作都没有意义了, 直接输出`No`。

② 某个数组段的最大字段和 = k, 这个时候我们把所有的`'0'`都赋为`-inf`（使得它们可以互相隔开）, 然后直接输出`Yes`。

③ 所有的数组段的最大字段和 < k, 这个时候如果没有让我们操作的`'0'`就直接输出`No`, 如果有，选择第一个`'0'`进行操作，其他的全部隔开（都赋为`-inf`）, 然后我们用两个变量`mx_pre`、`mx_suf`记录`'0'`之前的后缀和最大值，之后的前缀和最大值, 然后 $a[idx] = k - max(0, mx{pre}) - max(0, mx{suf})$。

## AC code ✅
```cpp
#include <bits/stdc++.h>

using i64 = int64_t;

constexpr i64 inf = 1e18;

void solve() {
  int n;
  i64 k;
  std::cin >> n >> k;

  std::string s;
  std::cin >> s;
  s = "0" + s + "0";

  std::vector<i64> a(n + 1); 
  for (int i = 1;i <= n; i++) {
    std::cin >> a[i];
  }

  auto fmx = [&](std::vector<i64>& b) -> i64{
    std::vector<i64> dp(b.size() + 1);
    dp[0] = b[0];
    i64 mx = b[0];
    for (int i = 1;i < b.size(); i++) {
      dp[i] = std::max(dp[i - 1] + b[i], b[i]);
      mx = std::max(mx, dp[i]);
    }
    return mx;
  };

  bool ok = true;
  std::vector<i64> b;
  for (int i = 1;i <= n + 1; i++) {
    if (s[i] == '0') {
      if (b.size() && fmx(b) > k) {
        ok = false;
        break;
      }
      b.clear();
    } else {
      b.push_back(a[i]);
    }
  }

  if (ok) {

    std::vector<i64> f(n + 1, -inf);
    i64 mx_sum = -inf;
    for (int i = 1;i <= n; i++) {
      f[i] = std::max(f[i - 1] + a[i], a[i]);
      mx_sum = std::max(mx_sum, f[i]);
    }

    if (mx_sum == k) {
      std::cout << "Yes\n";
      for (int i = 1;i <= n; i++) {
        std::cout << a[i] << " \n"[i == n];
      }
      return;
    }

    auto t = std::find(s.begin() + 1, s.end() - 1, '0');
    if (t == s.end() - 1) {
      std::cout << "No\n";
      return;
    } 

    int idx = t - s.begin();
    i64 pre = 0, suf = 0;
    i64 pre_mx = -inf, suf_mx = -inf;

    for (int i = idx - 1;i >= 1; i--) {
      pre += a[i];
      if (s[i] == '0') break;
      if (pre > pre_mx) {
        pre_mx = pre;
      }    
    }

    for (int i = idx + 1;i <= n; i++) {
      suf += a[i];
      if (s[i] == '0') break;
      if (suf > suf_mx) {
        suf_mx = suf;
      }      
    }

    for (int i = 1;i <= n; i++) {
      if (s[i] == '0' && i != idx) {
        a[i] = -inf;
      }
    }

    a[idx] = k - std::max(0LL, pre_mx) - std::max(0LL, suf_mx);

    std::cout << "Yes\n";
    for (int i = 1;i <= n; i++) {
      std::cout << a[i] << " \n"[i == n];
    }

  } else {
    std::cout << "No\n";
  }
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int t;
  std::cin >> t;

  while (t--) {
    solve();
  }

  return 0;
}
```

# D. Apple Tree Traversing 🌳

## 题目大意 🍎
有一棵苹果树，树上有 $n$ 个节点，最初每个节点上都有一个苹果。你随身带着一张纸，最初上面什么也没写。

只要苹果树上至少还剩下一个苹果，您就可以在苹果树上进行以下操作：

- 选择一条**苹果路径** $(u,v)$ 。当且仅当路径 $(u,v)$ 上的每个节点上都有一个苹果时，路径 $(u,v)$ 才被称为**苹果路径**。
- 假设 $d$ 是路径上苹果的个数，在纸上依次写下三个数字 $(d,u,v)$ 。
- 然后将小路上的苹果全部移走 $(u,v)$ 。

这里的路径 $(u, v)$ 是指从 $u$ 到 $v$ 的唯一最短路径上的顶点序列。

让纸上的数字序列为 $a$ 。你的任务是找出可能的最大序列 $a$ 。

## 题目思路 🤓

为了保证字典序最大, 我们第一步肯定是`树的直径`, 那么接下来该怎么办？

这是本道题的难点，但其实很简单，我们只需要把路径上的所有的点的子树进行同样的求`子树的直径`, 每次记录答案最后排序即可，不需要一定要先求直径，再求第二长。

记录路径我们用`pre`数组记住他的父亲即可。

## AC code ✨

### `dfs`求直径 🔍

```cpp
#include <bits/stdc++.h>

using i64 = int64_t;

void solve() {
  int n;
  std::cin >> n;

  std::vector<std::vector<int>> adj(n + 1);
  for (int i = 0;i < n - 1; i++) {
    int u, v;
    std::cin >> u >> v;
    adj[u].push_back(v);
    adj[v].push_back(u);
  }
  
  std::vector<std::array<int, 3>> ans;
  std::vector<bool> vis(n + 1, false);

  std::vector<int> p(n + 1), dis(n + 1, -1);
  int mx_dis = 0, idx = 0;
  std::vector<int> q;

  auto dfs = [&](auto dfs, int u, int fa) -> int{

    q.push_back(u);

    for (auto v: adj[u]) {
      if (v == fa || vis[v]) continue;
      p[v] = u;
      dis[v] = dis[u] + 1;
      dfs(dfs, v, u);
    }

    if (dis[u] > mx_dis) {
      mx_dis = dis[u];
    }

    return idx;
  };

  auto init = [&](int x) -> void{
    mx_dis = 0, idx = 0;
    p[x] = -1;
    dis[x] = 0;
    q.clear();
  };

  auto ddfs = [&](auto ddfs, int x) -> void{
    init(x);
    int a = dfs(dfs, x, 0);
    for (auto v: q) {
      if (mx_dis == dis[v] && !vis[v]) a = std::max(a, v);
    }
    init(a);
    int b = dfs(dfs, a, 0);
    for (auto v: q) {
      if (mx_dis == dis[v] && !vis[v]) b = std::max(b, v);
    }

    ans.push_back({mx_dis + 1, std::max(a, b), std::min(a, b)});

    for (int v = b; v != -1; v = p[v]) {
      vis[v] = true;
    }
    
    for (int v = b; v != -1; v = p[v]) {
      for (auto i : adj[v]) {
        if (!vis[i]) {
          ddfs(ddfs, i);
        }
      }
    }
  };

  ddfs(ddfs, 1);

  std::sort(ans.begin(), ans.end(), std::greater<>());

  for (int i = 0;i < ans.size(); i++) {
    std::cout << ans[i][0] << " " << ans[i][1] << " " << ans[i][2] << " \n"[i == ans.size() - 1];
  }
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int t;
  std::cin >> t;

  while (t--) {
    solve();
  }

  return 0;
}
```

### `bfs`求直径，来自于哥哥（Jiangly) 🚀
```cpp
#include <bits/stdc++.h>

using i64 = long long;
using u64 = unsigned long long;
using u32 = unsigned;

using i128 = unsigned __int128;
using u128 = unsigned __int128;

void solve() {
    int n;
    std::cin >> n;
    
    std::vector<std::vector<int>> adj(n);
    for (int i = 1; i < n; i++) {
        int u, v;
        std::cin >> u >> v;
        u--;
        v--;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    
    std::vector<std::array<int, 3>> ans;
    
    std::vector<bool> vis(n);
    
    std::vector<int> dis(n, -1), p(n);
    std::vector<int> q;
    auto bfs = [&](int x) {
        q = {x};
        dis[x] = 0;
        p[x] = -1;
        for (int i = 0; i < q.size(); i++) {
            int x = q[i];
            for (auto y : adj[x]) {
                if (y != p[x] && !vis[y]) {
                    dis[y] = dis[x] + 1;
                    p[y] = x;
                    q.push_back(y);
                }
            }
        }
        
        int t = x;
        for (auto x : q) {
            if (dis[x] > dis[t] || (dis[x] == dis[t] && x > t)) {
                t = x;
            }
        }
        return t;
    };
    
    auto work = [&](this auto &&self, int x) -> void {
        int a = bfs(x);
        int b = bfs(a);
        ans.push_back({dis[b] + 1, std::max(a, b) + 1, std::min(a, b) + 1});
        for (int i = b; i != -1; i = p[i]) {
            vis[i] = true;
        }
        for (int i = b; i != -1; i = p[i]) {
            for (auto x : adj[i]) {
                if (!vis[x]) {
                    self(x);
                }
            }
        }
    };
    
    work(0);
    
    std::sort(ans.begin(), ans.end(), std::greater());
    for (int i = 0; i < ans.size(); i++) {
        auto [d, u, v] = ans[i];
        std::cout << d << " " << u << " " << v << " \n"[i == ans.size() - 1];
    }
}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    
    int t;
    std::cin >> t;
    
    while (t--) {
        solve();
    }
    
    return 0;
}
```
